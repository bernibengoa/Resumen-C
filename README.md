## 🧩 1. Tipos de Datos

En C, los tipos de datos definen el tipo de valor que puede almacenar una variable.

### Tipos primitivos comunes:

| Tipo     | Tamaño (aprox) | Descripción                    |
|----------|----------------|--------------------------------|
| `int`    | 4 bytes        | Números enteros                |
| `float`  | 4 bytes        | Números decimales (menos precisión) |
| `double` | 8 bytes        | Números decimales de mayor precisión |
| `char`   | 1 byte         | Caracteres individuales         |

#### Ejemplo:

```c
int edad = 25;
float altura = 1.75;
char letra = 'A';
